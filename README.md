# Spotify Churn Analysis

## Project Overview

This repository presents a machine learning-based analysis of customer churn using Spotify user behavior data. The project applies predictive analytics and statistical modeling techniques to examine user engagement patterns, identify churn-related factors, and evaluate customer retention behavior.

The analysis is structured around seven research questions, each implemented through independent Jupyter notebooks with publication-ready outputs including visualizations, statistical summaries, and predictive model evaluation.

---

## Dataset Source

Spotify Dataset for Churn Analysis  
https://www.kaggle.com/datasets/nabihazahid/spotify-dataset-for-churn-analysis

---

## Research Questions

**RQ1:** Which user engagement features have the strongest influence on customer churn?

**RQ2:** How does premium subscription status impact customer retention?

**RQ3:** Can machine learning models accurately predict customer churn?

**RQ4:** Which listening behavior patterns are associated with churn probability?

**RQ5:** Which demographic segments show higher churn tendencies?

**RQ6:** Can distinct customer groups be identified using listening behavior clustering?

**RQ7:** What relationships exist between user interaction metrics and churn behavior?

## Methodology

The analysis applies the following techniques:

- Data preprocessing and cleaning
- Label encoding
- Exploratory data analysis
- Correlation analysis
- Logistic regression
- Random forest classification
- Feature importance analysis
- K-means clustering
- Principal component analysis (PCA)
- Statistical performance evaluation
